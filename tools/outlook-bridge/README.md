# Outlook Local Bridge

Standalone companion server that connects the **EQP System** to your local Desktop Microsoft Outlook.

## Requirements
- Windows OS
- Microsoft Outlook Desktop running and logged in
- Node.js (v18+)

## Quick Start
1. Unzip this folder anywhere on your computer.
2. Ensure desktop Outlook is open.
3. Double-click `start-bridge.bat`.
4. It will start listening on `http://127.0.0.1:5008`.
5. The EQP web system will automatically detect the bridge!
