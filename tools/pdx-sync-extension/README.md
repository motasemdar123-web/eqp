# EQP Komatsu PDX 1-Click Extension

This Edge/Chrome extension enables 1-click synchronization of your Komatsu PDX portal session to the EQP System without ever opening Developer Tools, Network tabs, or running console commands.

### Installation in Microsoft Edge / Chrome (Takes 30 seconds, 1-time setup):

1. Open **Microsoft Edge** and go to `edge://extensions` (or in Chrome: `chrome://extensions`).
2. Turn ON **"Developer mode"** (toggle in the left menu or top-right).
3. Click **"Load unpacked"** (top left).
4. Select the folder: `c:\Users\Motasem.ghanem\EQP-System\tools\pdx-sync-extension`.
5. Click the puzzle icon in your Edge toolbar and **Pin** the "EQP - Komatsu PDX Session Sync" extension.

### How to Use:
1. Whenever you log in to Komatsu PDX in Edge.
2. Click the EQP extension icon in your browser toolbar.
3. Click **"⚡ Sync Directly to EQP Server"** (or "Copy Full Cookie").
4. Done! Your session is instantly authenticated with the full `.AspNet.Cookies` security ticket.
